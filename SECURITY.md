# Security policy

## Supported versions

Only the latest release on `main` receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through [GitHub security advisories](https://github.com/fluki3-06s/songngan-mcp/security/advisories/new) with steps to reproduce and the version you tested.

You can expect an acknowledgement within a week. Once a fix is released, the advisory is published with credit unless you prefer otherwise.

## Scope

SongNgan runs locally with the user's own Google OAuth client. Reports about how it stores tokens, requests scopes, handles files and links, or exposes data to MCP clients are in scope. Problems in Google APIs or in MCP clients themselves should be reported to those projects.
